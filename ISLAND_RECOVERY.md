## 3. Этап 2. Привести интерфейс к текущему main.ts

Контракт задают `main.ts` и `preload.ts` — они актуальны. Подгонять под них нужно рендерер,
а не наоборот.

Опора — `ISLAND_MODES.md`, раздел за разделом:

- состояние `ViewMode { material, layout }` вместо строкового `compactView`, с миграцией
  старого ключа (раздел 1);
- материалы `black` / `artic` / `cactus` отдельно от раскладок (раздел 2);
- раскладки `minimal` / `timer` / `extended` / `task`, одинаковая высота компакта (раздел 3);
- раскрытие одним кликом, работающее во всех восьми режимах (раздел 4);
- геометрия подложки блюра из DOM, а не из констант (раздел 4, последний пункт).

Плюс из `ISLAND_FIXES.md`:

- драг на pointer events: `setPointerCapture`, проверка `e.buttons === 0`, порог 4 px
  в CSS-пикселях, 300 мс на клик, `pointercancel` и `window blur` закрывают сессию;
- **глобальный `setIgnoreMouseEvents(true)` не возвращать.** Его уже убирали: он делал окно
  прозрачным для мыши, из-за чего пропадали клики, не листались иконки правой кнопкой, а
  потерянный `pointerup` оставлял сессию драга открытой — и остров ехал от наведения.
  Сквозные зазоры в `extended` делаются `pointer-events: none` на контейнере и
  `pointer-events: auto` на самих фигурах;
- значок в `extended` только в левом круге, в центральном pill его быть не должно;
- стекло: тинт компакта светлее тинта раскрытой панели, нижнего затенения нет,
  остаётся только верхний блик.

В `theme.css` вёрстки под `extended` нет — её придётся дописать. Остальное в нём свежее,
не переписывай файл целиком, добавляй.

Собери, проверь, покажи результат. Коммит.

`TaskItem.tsx` его не получает: заголовок выводится просто текстом в `div.task-title`.

1. Двойной клик по заголовку превращает его в `input` с текущим текстом:
   - Enter или потеря фокуса сохраняют через `updateTaskTitle`;
   - Esc отменяет, возвращает прежний текст;
   - пустая строка не сохраняется;

     `onActivate` и в драг острова;

3. То же для подзадач: двойной клик по `subtask-title`. Метода для этого нет — добавить
   `updateSubtaskTitle(taskId, subtaskId, title)` в `tasksStore` рядом с `removeSubtask`

## 5. Этап 4. Выбор нескольких скриншотов

Сейчас в `ScreenshotsPanel.tsx` всё поштучно: клик копирует, `×` удаляет, drag отдаёт файл
в ОС, Alt+drag меняет порядок. API в `preload.ts` тоже поштучный: `deleteScreenshot`,
`copyScreenshot`, `reorderScreenshots`, `startScreenshotDrag` — все принимают один id.

1. Выделение:
   - Ctrl+клик добавляет или убирает карточку из выделения;
   - Shift+клик выделяет диапазон от последней выделенной до текущей;
   - обычный клик работает как сейчас (копирует одну) и сбрасывает выделение;
   - Esc и клик по пустому месту сетки снимают выделение;
   - Ctrl+A выделяет всё, пока панель в фокусе.
2. Вид: `shot-card--selected` — рамка акцентным цветом и галочка в углу. Сетку не переделывать.
3. Панель действий появляется над сеткой, когда выделено больше нуля:
   «Выбрано N» · Копировать · Сохранить в папку · Удалить · Снять выделение.
   - удаление подтверждается в самой панели (кнопка меняется на «Удалить N?»),
     **без системного диалога** — модальные окна блокируют Electron;
   - сохранение в папку через `dialog.showOpenDialog` с `properties: ['openDirectory']`;
   - копирование нескольких картинок в буфер Windows штатно не делается. Клади их как
     список файлов (`clipboard.writeBuffer` с `CF_HDROP`). Если это окажется сложно —
     скопируй первую и скажи, обсудим.
4. Drag нескольких: если тащат выделенную карточку, отдавать в ОС все выделенные файлы
   сразу (`startDrag` с массивом `files`), а не одну.
5. IPC: сделать пакетные каналы `island:delete-screenshots`, `island:copy-screenshots`,
   `island:save-screenshots-to` (принимают массив id). Не вызывать поштучные в цикле —
   иначе на удалении будет N перерисовок списка.
6. `index.json` в папке скриншотов обновлять одной записью после всей операции.

Папка: `%AppData%\pc-dynamic-island\island-screenshots`

## 6. Запреты

Каждый пункт уже ронял или прятал остров:

- никакого `SetWindowRgn` и `setShape` на окне Electron;
- не трогать child-HWND Chromium (`Chrome_WidgetWin_1`, render widget, D3D);
- без `koffi` и `GetClientRect` для размеров — только `bounds` через `screen.dipToScreenRect`;
- не включать Acrylic одновременно с подложкой `IslandBackdrop.exe`;
- не возвращать глобальный `setIgnoreMouseEvents(true)`;
- `island-state.json` править **только** через `node` + `JSON.parse`, никогда через
  PowerShell `ConvertTo-Json`: так уже обнулялись `tasks`. Там 18 задач, таймеры,
  карта активности и `iconChoice` — сохранять все ключи целиком;
- не переписывать файл целиком «с нуля», если правится часть. Так и потеряли `IslandShell.tsx`.
